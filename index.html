HTML 5

Annexe HTML5

Baccalauréat STI - Sciences & Technologies de l'Informatique
👆 Interactif : Cliquez sur n'importe quelle balise pour voir les variantes avec boutons radio & rendu animé !
Éléments de 1er niveau
<html> Représente la racine d'un document HTML.
<head> Conteneur de métadonnées placé entre la balise <html> et la balise <body>.
<body> Définit le corps du document.
Éléments d'en-tête
<link> Définit la relation entre le document actuel et une ressource externe.
Attributs : href, rel, type
<meta> Définit les métadonnées du document.
Attributs : charset, name, content
<script> Intègre un script côté client (JavaScript).
Attributs : src, type
<style> Définit les informations de style (CSS) pour un document.
Attributs : type, media
<title> Définit le titre du document.
Éléments de structuration d'une page web
<header> Conteneur pour le contenu d'introduction ou un ensemble de liens de navigation.
<nav> Définit un ensemble de liens de navigation.
<footer> Définit un pied de page pour un document ou une section.
<section> Définit une section dans un document.
<article> Spécifie un contenu indépendant et autonome.
<aside> Définit un contenu en dehors du contenu principal (barre latérale).
<main> Définit le contenu principal d'un document.
Conteneurs
<span> Regroupe des éléments dans un bloc de contenu en ligne (inline).
<div> Grouper plusieurs éléments Html de type block.
<iframe> Définit un cadre en ligne.
Attributs : src, name
Listes
<ul> Définit une liste à puces (non ordonnée).
<ol> Définit une liste ordonnée.
Attributs : reversed, type, start
<li> Définit un élément dans une liste.
Éléments de structuration de texte et média
<cite> Définit le titre d'une œuvre.
<p> Définit un paragraphe.
<source> Spécifie plusieurs ressources multimédias pour les éléments multimédias.
Attributs : src, type, media
<h_n> Définit un titre de niveau n (de 1 à 6).
<hr> Définit une rupture thématique sous forme de ligne horizontale.
<img> Intègre une image.
Attributs : src, alt
<figure> & <figcaption> Spécifie un conteneur autonome avec légende pour des médias.
<audio> Intégrer du contenu sonore dans un document.
Attributs : controls, src
<video> Intègre du contenu vidéo dans un document.
Attributs : controls, src
<a> Définit un lien hypertexte via l'attribut href.
Attributs : href, target
<br> Définit un retour à la ligne.
<address> Définit les coordonnées de l'auteur/propriétaire d'un document.
<mark> Définit le texte qui doit être marqué ou mis en surbrillance.
<details> & <summary> Spécifie des détails supplémentaires pliables/dépliables avec en-tête visible.
Attribut : open
Tableau
<table> Définit un tableau HTML structuré.
<thead>, <tbody>, <tfoot> Définit l'entête, le corps et le pied d'un tableau.
<caption> Définit une légende de tableau.
<tr>, <th>, <td> Ligne (<tr>), cellule d'entête (<th>) et cellule standard (<td>).
Attributs globaux
class Spécifie un nom de classe pour un élément.
id Spécifie un identifiant unique pour un élément HTML (fondamental au Bac STI).
hidden Renseigne la visibilité d'un élément (masqué).
lang Spécifie la langue du contenu de l'élément (ex: lang="fr").
style Spécifie un style en ligne CSS.
title Spécifie des informations supplémentaires sous forme d'infobulle au survol.
Éléments de formulaire
<form> Crée un formulaire HTML.
Attributs : action, method ("post", "get"), onsubmit="return validerFormulaire()"
<fieldset> & <legend> Regroupe des éléments liés avec un titre d'encadré <legend>.
<label> Définit un libellé pour un élément graphique (attribut for).
<input> 🎛️ Définit un champ de saisie : text, password, email, number, date, range, checkbox, radio, submit, reset, button.
<textarea> Définit une zone de saisie de texte multilignes.
cols, rows, readonly, required, maxlength
<select> & <option> Définit une liste déroulante et ses options sélectionnables.
<datalist> pour suggestions prédéfinies
Evènements (Conforme Bac STI)
onclick Se déclenche lors d'un clic sur l'élément.
onmouseover Se déclenche lorsque le pointeur de la souris survole l'élément.
onmouseout Se déclenche lorsque le pointeur de la souris sort de l'élément.
onfocus Se déclenche au moment où l'élément obtient le focus.
onblur Se déclenche au moment où l'élément perd le focus.
oninput Se déclenche dès que la valeur d'un élément a changé.
onchange Se déclenche lorsque la valeur d'un élément est modifiée (validation/perte de focus).
onsubmit Se déclenche lorsqu'un formulaire est soumis (onsubmit="return valider()").
onkeydown Se déclenche lorsqu'une touche du clavier est pressée.
onkeyup Se déclenche lorsqu'une touche est relâchée.
onload Se déclenche lorsque la page est complètement chargée.
onplay Se déclenche lorsque la lecture d'un fichier audio/vidéo commence.
onpause Se déclenche lorsqu'un élément audio/vidéo est mis en pause.

CSS 3

Annexe CSS3

Baccalauréat STI - Sciences & Technologies de l'Informatique
👆 Interactif : Cliquez sur n'importe quelle propriété pour voir les variantes avec boutons radio & vidéo animée !
Sélecteurs
* Sélectionne tous les éléments.
element Sélectionne tous les éléments de type element.
#id Cible un élément en fonction de la valeur de son attribut id. (Sélecteur officiel Bac STI)
.class Cible les éléments en fonction de la valeur de leur attribut class.
element[attr] Cible les éléments qui possèdent l'attribut attr.
element[attr=valeur] Cible les éléments en fonction de la valeur de l'attribut attr.
element.class Cible tous les éléments de type element ayant la classe class.
a:link Cible tous les liens non visités.
a:visited Cible tous les liens visités.
a:hover Cible l'élément au moment où l'utilisateur le survole avec le pointeur de la souris.
a:active Cible tous les liens activés.
Remarque: pour grouper plusieurs sélecteurs dans une règle, il suffit de les lister en les séparant par des virgules ",". 👆
Propriétés de mise en forme du texte
font-family Spécifie les noms de polices possibles par ordre de préférence.
font-weight 🎛️ Spécifie la manière dont les caractères d'un texte doivent être affichés (bold ; bolder ; lighter).
font-style Spécifie le style d'un texte (italic).
font-size Spécifie la taille d'une police (px, %).
font Super-propriété de font. Combine font-family, font-weight, font-style, font-size.
text-align 🎛️ Spécifie l'alignement horizontal d'un texte (left ; center ; right ; justify).
text-shadow Définit une ombre au texte.
text-transform 🎛️ Spécifie la façon de transformer les caractères en majuscules ou minuscules (uppercase ; lowercase ; capitalize).
color 🎛️ Spécifie la couleur du texte.
Propriétés des listes
list-style-type 🎛️ Définit le type de marqueur d'éléments de liste (circle ; square ; upper-roman ; lower-alpha).
list-style-position Spécifie la position des marqueurs d'éléments d'une liste à puces (outside ; inside).
list-style-image Spécifie une image comme marqueur d'éléments de liste.
list-style Super-propriété de liste. Combine list-style-type, list-style-position, list-style-image.
Propriétés des tableaux
table-layout Définit la façon de disposer les cellules, lignes et colonnes d'un tableau.
border-collapse 🎛️ Définit si les bordures des cellules sont fusionnées ou séparées (separate ; collapse).
Propriétés des boîtes
width Définit la largeur d'un élément (px, %).
height Définit la hauteur d'un élément.
position Spécifie le type de positionnement utilisé (absolute ; fixed ; relative ; static ; sticky).
float Place/Fait flotter un élément dans un conteneur (left ; right ; none).
padding Propriété abrégée qui définit la marge intérieure d'un élément des 4 cotés.
margin Définit les marges extérieures d'un élément.
box-shadow 🎛️ Ajoute des ombres à la boîte d'un élément.
display 🎛️ Spécifie le comportement d'affichage d'un élément (inline ; block ; inline-block).
top, bottom, left, right Spécifie la position verticale et horizontale par rapport aux bords.
overflow 🎛️ Spécifie le comportement du contenu lorsqu'il déborde (visible ; hidden ; clip ; scroll ; auto).
opacity 🎛️ Définit le niveau de transparence.
Arrière-plan, Transformation & Filtres
background-color Définit la couleur d'arrière-plan d'un élément.
background-image Définit une image d'arrière-plan pour un élément.
background-repeat 🎛️ Définit la façon dont une image d'arrière-plan est répétée (repeat ; repeat-x ; repeat-y).
background-size Spécifie la taille d'une image d'arrière-plan (cover, contain, %).
background Super-propriété d'arrière-plan combinée.
transform 🎛️ Applique un effet de transformation 2D ou 3D (rotate(), skew(), scale(), translate()).
filter 🎛️ Définit des effets visuels à un élément (blur() ; grayscale() ; sepia()).
Propriétés des bordures
border-color 🎛️ Définit la couleur des bordures d'un élément.
border-style 🎛️ Définit le style des bordures : solid, dotted, dashed, double, groove, ridge.
border-radius 🎛️ Définit le rayon des coins arrondis d'un élément (px, %).
border-width 🎛️ Définit la largeur des bordures (medium ; thin ; thick ; valeur en px).
border 🎛️ Super-propriété de bordure. Combine border-color, border-style, border-width, border-radius.
Transition
transition-delay Spécifie le délai nécessaire avant que la transition commence.
transition-duration Spécifie la durée de la transition.
transition-property Spécifie les propriétés CSS sur lesquelles l'effet de transition sera appliqué.
transition Super-propriété de transition combinée.
Animation
@keyframes Spécifie les états clés de l'animation.
animation-name Spécifie le nom de l'animation.
animation-delay Spécifie le délai nécessaire avant que l'animation commence.
animation-duration Spécifie la durée de l'animation.
animation-iteration-count Spécifie le nombre de répétition de l'animation (infinite...).
animation-direction Définit la direction de l'animation (normal, reverse, alternate...).
animation Super-propriété de l'animation combinée.
Important: pour exprimer les mesures des dimensions, se limiter aux unités (pixel et %). Note :hover systématique avec #id.

+ Addition

Méthodes pour afficher une sortie*
alert() Affiche un message dans une boîte de dialogue.
Document.write() Affiche directement dans le document HTML.
*Pour afficher/modifier un contenu dynamique, on peut utiliser la propriété innerHTML d'un élément HTML. 👆
Méthode pour saisir une entrée
prompt() Affiche une boîte de dialogue avec une zone de saisie.
Fonctions/Méthodes JS
isNaN(ch) Retourne true si l'argument ch n'est pas convertible en un nombre, sinon retourne false.
Number(ch) Convertit une chaîne ch en un nombre*.
parseFloat(ch) Convertit une chaîne ch en un réel.
parseInt(ch [,b]) Convertit une chaîne ch en un entier exprimé dans la base b.
String(a) Convertit la valeur a en une chaîne.
*Si la conversion n'est pas possible, la fonction retourne NaN.
Méthodes pour sélectionner des éléments HTML
document.getElementById() permet de sélectionner un élément unique en fonction de son identifiant.
document.getElementsByName() permet de sélectionner tous les éléments ayant le même nom.
Méthodes de l'objet Math (Math)
abs(x) Retourne la valeur absolue.
sqrt(x) Retourne la racine carrée.
round(x) Retourne l'entier le plus proche.
trunc(x) Retourne la troncature entière d'un nombre en retirant sa partie décimale.
random() Retourne un réel aléatoire dans [0, 1[.
Les chaînes de caractères
+ Opérateur de concaténation.
ch.length Propriété qui retourne la longueur de ch.
ch.indexOf(ch1 [,p]) Retourne la position de la 1ère occurrence de ch1 dans ch, en effectuant la recherche à partir de la position p (sinon -1).
ch.lastIndexOf(ch1 [,p]) Retourne la position de la dernière occurrence de ch1 dans ch à partir de la position p.
ch.substring(d, f) Retourne une sous-chaîne de ch de la position d à la position f (non incluse).
ch.replace(ch1, ch2) Retourne une chaîne dans laquelle la 1ère occurrence de ch1 dans ch est remplacée par ch2.
ch.toLowerCase() Convertit tous les caractères de ch en minuscules.
ch.toUpperCase() Convertit tous les caractères de ch en majuscules.
ch.trim() Supprime tous les espaces existants au début et à la fin de ch.
String.fromCharCode(num, ..., numN) Retourne une chaîne formée par la concaténation des résultats de conversion des codes ASCII passés en paramètres.
ch est un objet String
L'objet Date
new Date() Retourne la date courante.
new Date(ch) Retourne un objet Date à partir d'une chaîne de caractères ch représentant une date.
d.getDate() Retourne le jour du mois (entre 1 et 31).
d.getMonth() Retourne le numéro du mois (entre 1 et 11).
d.getFullYear() Retourne la valeur de l'année sur 4 chiffres.
d.toString() Retourne une chaîne de caractères représentant la date d.
d est un objet Date.
L'objet Array
length Propriété qui représente le nombre d'éléments dans un tableau.
Pour créer un tableau, utiliser les littéraux de tableau []. 👆
Modification du contenu, des attributs ou des styles des éléments HTML
element.attribut = valeur Change la valeur de l'attribut d'un élément HTML.
Se limiter à la manipulation des attributs value, checked, disabled, readonly, src, muted.
element.style.propriété = valeur Change le style d'un élément HTML.
Se limiter à la manipulation des propriétés color, background, border, font, width, height.
element.méthode() Effectue une action sur un élément HTML (play / pause).
Se limiter à la manipulation des méthodes play(), pause().
Pour une liste déroulante (<select>) : utiliser la propriété selectedIndex pour récupérer l'indice de l'option sélectionnée. 👆
